# Сияние — backend (регистрация по email)

Минимальный API на FastAPI: регистрация, подтверждение почты кодом, вход.

## Локальный запуск (для проверки)

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
```

По умолчанию, если не задать `DATABASE_URL`, используется локальный файл
SQLite `siyanie_dev.db` — ничего дополнительно ставить не нужно, чтобы
просто проверить, что всё работает.

Открой `http://127.0.0.1:8000/docs` — там автоматическая страница со всеми
эндпоинтами, можно потыкать прямо из браузера.

Пока не настроен SMTP, код подтверждения просто печатается в консоль сервера
(смотри строку `[DEV EMAIL] ...`).

## Деплой на Railway (бесплатно для старта)

1. Зарегистрируйся на railway.app
2. Создай новый проект → "Deploy from GitHub repo" (или "Empty project" и
   залей файлы вручную)
3. Добавь плагин PostgreSQL — Railway сам создаст `DATABASE_URL` и
   подставит его как переменную окружения
4. В настройках проекта добавь переменные из `.env.example`:
   - `JWT_SECRET` — своя случайная строка
   - `SMTP_*` — если уже завёл почтовый сервис для рассылки
5. Railway сам определит команду запуска, либо укажи вручную:
   `uvicorn app.main:app --host 0.0.0.0 --port $PORT`

## Деплой на Render — то же самое, только:
- Тип сервиса: Web Service
- Build command: `pip install -r requirements.txt`
- Start command: `uvicorn app.main:app --host 0.0.0.0 --port $PORT`
- Базу PostgreSQL можно создать там же, в Render, отдельным ресурсом

## Что дальше

- Подключить сайт: форма регистрации отправляет POST на `/register`,
  форма с кодом — на `/verify`, дальше сохраняешь `access_token` и
  используешь его в заголовке `Authorization: Bearer <token>` для
  остальных запросов
- Добавить регистрацию по телефону — по той же схеме, но вместо
  `email_utils.py` нужен модуль отправки SMS (например, SMS.ru или SMSC —
  они работают с российскими номерами)
- Когда дойдёт до чатов и сообщений — расширить `models.py` таблицами
  `chats`, `chat_members`, `messages`, как в изначальной схеме, и добавить
  эндпоинты для отправки/получения сообщений
